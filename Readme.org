* 需求
这是一个新项目，我想开发一个自己笔记系统。实现我在家，手机，公司书籍阅读，笔记同步等需求
* 架构
- 服务端：管理，整理笔记等功能，主要用于外网可访问。所有端的数据都从服务端的数据汇总。也支持一些二进制附件的存储。
- 客户端：我的笔记主要机遇 Emacs 的 org-mode 的，分为桌面端和手机端。桌面端只需要同步进行，笔记可以复用 Emacs 的Org mode 等笔记设施设施。手机端只支持 Android. 需要有两个功能一个笔记阅读，批注等等，需要支持电子书 epub, mobi, pdf 等文档查看批注（类似于静读天下 app, 但是功能没有那么复杂，专注阅读，批注等）。第二个功能是支持 org gtd 类似于 orgzly  app 查看 org-mode gtd 信息。
- 桌面端 Emacs 需 32.0+：阅读器渲染后端使用 Emacs 32 的 canvas 图像对象（编译期特性），29/30/31 不支持
* 要求
1. 服务端存放的数据需要加密，可索引查询。
2. 支持 webdav 功能。
3. 三端需要同步阅读进度，批注等等状态。
* 阅读器渲染默认行为（P2-B 起，2026-10-29）
- 桌面端 Emacs 阅读器改为**两阶段渲染**：滚动进入新页时先按最终页高把布局立起来（占位态），像素由 idle / 周期 timer 在命令返回后补上；可能出现短暂的「空白 → 清晰」过渡，但页高与滚动范围不变、不会跳变。
- 正在看的页（point 页 + 滚动方向相邻页）始终同步渲染；队列超过 =seshat-reader-render-async-timeout=（默认 1.0 秒）未排空则强制同步。
- 回滚：=(setq seshat-reader-render-async nil)= 回到逐页同步渲染（布局逐字节等价，只差渲染时机）；渲染模块改动需重编 .so 并重启 Emacs。
- 相关选项：=seshat-reader-render-async= / =-render-async-timeout= / =-render-idle-delay=（周期推进间隔，不是 idle 延迟）/ =-render-idle-batch=，详见 =docs/configuration.md= 的「阅读器两阶段渲染」一节。
