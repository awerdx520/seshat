* 需求
这是一个新项目，我想开发一个自己笔记系统。实现我在家，手机，公司书籍阅读，笔记同步等需求
* 架构
- 服务端：管理，整理笔记等功能，主要用于外网可访问。所有端的数据都从服务端的数据汇总。也支持一些二进制附件的存储。
- 客户端：我的笔记主要机遇 Emacs 的 org-mode 的，分为桌面端和手机端。桌面端只需要同步进行，笔记可以复用 Emacs 的Org mode 等笔记设施设施。手机端只支持 Android. 需要有两个功能一个笔记阅读，批注等等，需要支持电子书 epub, mobi, pdf 等文档查看批注（类似于静读天下 app, 但是功能没有那么复杂，专注阅读，批注等）。第二个功能是支持 org gtd 类似于 orgzly  app 查看 org-mode gtd 信息。
* 要求
1. 服务端存放的数据需要加密，可索引查询。
2. 支持 webdav 功能。
3. 三端需要同步阅读进度，批注等等状态。
