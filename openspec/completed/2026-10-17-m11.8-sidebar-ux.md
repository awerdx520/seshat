## 背景

M11.7 的底部面板已可用（真机验证通过），但三项体验缺口：

1. **光标不跟随**：面板弹出后光标仍在阅读窗口（`display-buffer` 默认不选窗口），要点进去才能操作；
2. **无 popper 集成**：用户已有 popper 体系（`C-'` / `M-`` 开关、`popper-cycle`），但 `*Seshat Annotations*` 与 `*Seshat Sidebar*` **未被登记**（`init-window.el:54-113` 的清单里没有），无法用 popper 一键开关；
3. **键位不足**：批注面板在 evil 下 `RET`/`d` 被 evil 吃掉（`init-evil.el` 无任何 annotation 相关绑定）；面板也没有全局快捷入口。

## 目标

1. 面板弹出后**光标跟随**（命令结束时进入面板），且可由 defcustom 关闭；
2. 把两个面板 buffer **登记到 popper**（可用 `C-'` / `M-`` / `popper-cycle` 开关/切换），但**布局仍由本包控制**（`position`/`height`/per-kind 高度不受 popper 影响）；
3. 提供**全局快捷入口**（`SPC o P` 前缀）与**面板内键位**（批注面板 evil 补绑、译文面板裸 `q`）；
4. 不改变 M11.7 已确认的回退语义（`sidebar-enabled=nil`、`translate-render=pop`）。

## 设计

### ① 光标跟随（仅批注面板）

- 新增 defcustom `seshat-reader-sidebar-select-window`（默认 `t`）。
- **只对批注面板生效**：`--display-params` 增加可选参数（如 `(&optional kind select)`），只有 `--display`（批注路径）传 `select` 为非 nil 时才追加 `(post-command-select-window . t)`；**译文路径不传**（`translate.el` 调 `--display-params 'translate` 保持无 select）。
- 理由（审查发现）：`gt-buffer-render` 在翻译**启动**命令内即 `display-buffer`，若加 select 会把光标抢进空白的 Loading 面板；而翻译**完成**时 gt 自己用裸 `display-buffer`，不受该键影响 → 半残。译文面板的「完成时跟随」不在本步（记 tech-debt 备选：用 `gt-buffer-render-follow-p` 或 `:then`）。
- `RET`（`seshat-reader-annotation-list-goto`）**不需要改动**：`post-command-select-window` 的 postfun 是一次性的、只在 `--display` 所在命令结束时触发；`goto` 是另一个命令，不重新触发。**删除原 T4**，改为 ERT 护栏断言（见 T9）。

### ② popper 集成（登记 + 开关，布局仍由本包掌控）

**问题（审查发现）**：popper 重开 popup 时用**裸 `display-buffer`**（`popper-open-latest`），此时若只靠 `--display` 里的 `display-buffer-overriding-action`，重开后会命中 popper 在 `display-buffer-alist` 表头的规则 → 漂移为 bottom side window、丢失 `seshat-reader-sidebar` window-parameter 与 per-kind 高度。

**修法（display-function 分流，不依赖 alist 顺序）**：
- `seshat-reader-sidebar.el` 新增两个符号：
  - `seshat-reader-sidebar-buffer-p (buffer)`：按 buffer 名判定是否本包面板（`seshat-reader-annotation-list-buffer-name` 或 `seshat-reader-sidebar-translate-buffer-name`）；
  - `seshat-reader-sidebar-display-buffer (buffer alist)`：**popper 兼容的 display 函数**（签名 `(buffer alist)`），按 buffer 名推断 KIND（annotations / translate），调用本包显示逻辑（`--display` 或 `--display-params` + `display-buffer`），返回窗口。
- `thomas-emacs/lisp/init-window.el` 的 `+popper-smart-popup-at-bottom`（`init-window.el:158-164`）加分支：`(if (and (fboundp 'seshat-reader-sidebar-display-buffer) (seshat-reader-sidebar-buffer-p buffer)) (seshat-reader-sidebar-display-buffer buffer alist) ...原有逻辑...)`。
- 效果：popper 的「开 → 关 → 重开」与首次显示**同一布局**（普通分割 + `position`/`height`/per-kind），且 popper 仍登记为 popup（`popper-popup-p` 只看 buffer 名，与窗口由谁创建无关）。
- **不改** `popper-display-control`（全局影响其它 popup）。
- 保底：`seshat-reader-sidebar-toggle` 继续存在，并注明与 popper 的分工（popper 负责 `C-'`/`M-`` 开关；本包 toggle 负责可靠关闭 + 状态捕获）。

### ③ 键位
**全局（`SPC o P` 前缀，新增）**：

| 键 | 命令 | 说明 |
|---|---|---|
| `SPC o P p` | `seshat-reader-sidebar-toggle` | 开关面板（可靠路径） |
| `SPC o P a` | `seshat-reader-annotation-list` | 打开批注面板 |
| `SPC o P t` | `seshat-reader-translate-selection` | 翻译选区（结果进面板） |
| `SPC o P e` | `seshat-reader-translate-explain-selection` | 解释选区 |

**批注面板内（`init-evil.el` 补绑，解决 F8）**：`RET` → `list-goto`、`d` → `list-delete`、`q` → `seshat-reader-sidebar-toggle`（不绑 `C-c C-r`——已由 `seshat-reader-reference.el` 绑在 `seshat-reader-annotation-list-mode-map`，evil 不吃 `C-c` 前缀；真机验证时确认可用）。
**译文面板（`*Seshat Sidebar*`）**：在 `gt-buffer-render-init-hook` 中补**裸 `q`** → `delete-window`（evil normal state 下也生效），与 gt 的 `,q` 并存。

### 明确不在本步（范围外）

改 `popper-display-control`、改面板布局（position/height/per-kind 保持）、popper 的 `popper-cycle` 自定义分组、ETAF 迁移、Android/Web、页面高亮。

## 注意事项

- **布局不变量**：`position`/`height`/per-kind 高度语义**不得**因 popper 改变（这是本步的核心目的）；若 T2 实测 overriding-action 不能压过 popper，须停下报告，不要退化成「接受 popper 布局」
- **不放宽回退**：`seshat-reader-sidebar-enabled=nil` 与 `translate-render=pop` 仍须回到原行为
- **不改全局 popper 配置**：`popper-display-control`、`popper-window-height` 一律不动（会影响用户其它 popup）
- **evil 只改配置侧**：`init-evil.el` 是用户配置，包内不得依赖 evil
- **命名不变量**：新符号前缀 `seshat-reader-sidebar-`
- **计划文件编辑方式**：该仓库的 Markdown 计划曾出现编辑工具静默截断；改计划文件时用「读全文 → 内存替换 → 整体写回」并先备份
- **范围纪律**：不做 popper 自定义分组、不改面板布局、不做 ETAF 迁移 —— 越界即停并报告
- **popper 关闭不捕获 per-kind 状态**：popper 的 `popper--delete-popup` 走 `quit-window`，不调本包 `--capture-state`；用户在 popper 关闭前手动 resize 的高度不会被记住（best-effort，接受为已知差异）
- **`SPC o P` 仅在 evil 的 normal/visual/motion 态生效**（`leader!` 的定义域），insert/emacs 态无此绑定
- **译文面板的「完成时跟随」不在本步**：`gt-buffer-render` 完成时用裸 `display-buffer`，不受 `post-command-select-window` 影响；如需跟随，另用 `gt-buffer-render-follow-p` 或 `:then`（记 tech-debt）
- **popper 名单为硬编码正则**：`seshat-reader-sidebar-translate-buffer-name` 是 defcustom，若用户改其值，popper 将不再登记该面板（`C-'` 开关失效）；已知限制，记入文档
