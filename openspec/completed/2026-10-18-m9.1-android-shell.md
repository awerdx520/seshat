## 目标

为 Android 端建立可承载 Notes / Reader 两域内容的单 Activity 壳（顶部工具栏 + 中部内容区 + 底部 Notes·Reader 双 tab），并提供 App 内唯一能写入服务端配置的设置页。既有功能（GTD / EPUB 阅读 / PDF 阅读 / 书籍导入）零丢失、零业务改动。

可机械判定的验收标准：

1. `cd android && ./gradlew :app:assembleDebug` 成功（L1）。
2. `cd android && ./gradlew :app:testDebugUnitTest` 全绿：既有 136 例保持通过 + 新增 ≥22 例、用例总数 ≥158（L2）。
3. APK 的 manifest 含 5 个 Activity：`MainActivity`、`SettingsActivity`、`GtdActivity`、`EpubReaderActivity`、`PdfReaderActivity`（L3 降级项，用 `aapt2 dump badging` / `apkanalyzer manifest print` 静态校验）。
4. 设置页保存后杀进程重启仍保留配置（L3 降级项，人工真机验收）。
5. 既有 4 个阅读入口（示例 EPUB / 选 EPUB / 选 PDF / 导入书籍）与 GTD 入口均从新骨架可达（L3 降级项，人工真机验收）。

## 设计

### 目标结构

| 区域 | 组成 |
|---|---|
| 顶部工具栏 | `MaterialToolbar`，标题随 tab 变化（笔记 / 阅读），overflow 菜单项「设置」 |
| 内容区 | `FragmentContainerView`，承载 `NotesFragment`（默认）与 `ReaderFragment`，show/hide 切换保留状态 |
| 底部 | `BottomNavigationView` 双项（Notes / Reader），仅文字标题，不引入 drawable 图标 |

### 新增/改造类

| 类 | 动作 | 职责 |
|---|---|---|
| `MainActivity.kt` | 改造（现 87 行 → 约 140 行） | Shell 宿主：setSupportActionBar、BottomNav 监听、Fragment show/hide、tab 状态恢复、菜单「设置」入口 |
| `ui/MainTab.kt` | 新增（纯逻辑，无 Android 依赖） | `enum class MainTab { NOTES, READER }` + `restore(savedIndex: Int?): MainTab` + `indexOf(tab): Int` |

### 关键决策（用户 2026-10-18 确认）

| # | 决策 | 理由 |
|---|---|---|
| D1 | 继续 View/XML + Material Components，不引入 Compose | 现有 3274 行全为 View/XML；M9.1 是骨架不是重写 |
| D2 | 手写 Fragment show/hide，不引入 Navigation Component | 仅 2 个 tab，无深层栈；`androidx.navigation` 未在 Gradle 缓存 |
| D3 | 零新增依赖（仅显式声明 `androidx.fragment:fragment:1.5.4` 固定版本） | 全部命中本机 Gradle 缓存，离线可解析 |
| D4 | 设置页用独立 Activity + 自定义布局 + `SecurePrefs`，不用 `PreferenceFragmentCompat` | `SecurePrefs` 的加密创建与回退必须走代码；`PreferenceFragmentCompat` 直接操作 `SharedPreferences` 会绕过加密；`androidx.preference` 未缓存 |
| D5 | 设置页令牌不回填明文，显示「已配置 / 未配置」，留空即不修改 | 减少令牌在 UI 驻留 |
| D6 | 阅读器（`EpubReaderActivity` / `PdfReaderActivity`）保持独立全屏 Activity | 沉浸阅读不占内容区，零回归 |
| D7 | 设置页不做「测试连接」（无网络调用） | 骨架阶段不引入网络路径，留给 M9.2 |
| D8 | BottomNav 仅文字标签，不新增 drawable | 无设备无法验证图标渲染；记入 tech-debt |
| D9 | 不引入协程 / ViewModel / Room | 本阶段唯一异步是设置页本地写 prefs（毫秒级） |

## 注意事项

- **TDD 强制**：T2 必须先提交测试并看到失败（红），再写实现（绿）。不得先写实现再补测试。
- **既有测试是护栏**：T1–T5 任一步骤导致既有 136 例中任一失败，视为回归，必须修复而非改测试期望。
- **`registerForActivityResult` 时机**：Fragment 中必须在字段初始化阶段调用（早于 `onCreate`）；放到 `onCreateView` 之后会抛 `IllegalStateException`。
- **`SecurePrefs.open()` 只调用一次**：`EncryptedSharedPreferences.create` 有解密开销，不要在 `getString` 前后重复 open。
- **字符串复用**：`reader_open_sample`、`reader_pick_file`、`main_open_pdf`、`main_import_file`、`main_open_gtd` 等既有字符串继续复用，不要重复定义同义新串（避免 lint 重复资源）。
- **不新增 drawable**：BottomNav 与 Toolbar 均只用文字；`app:navigationIcon="?attr/homeAsUpIndicator"` 若在 L1 报资源解析错误，降级为不设返回箭头（用系统返回键）。
- **`activity_main.xml` 老 id 不可残留引用**：`helloText`（丢弃）、`openSampleButton` / `pickEpubButton` / `openPdfButton` / `importButton`（迁至 `fragment_reader.xml`）、`openGtdButton`（迁至 `fragment_notes.xml`）。迁移后 `MainActivity` 不得再 `findViewById` 它们，否则运行期 NPE（L1 编译不报错）。
- **容器验证不适用**：本项目无 `make test-in-docker`，Android 构建为宿主 Gradle，属规则中的例外情形（验证对象与容器无关）。
- **安全**：实施过程中不得把 `keystore.properties`、`release.keystore`、`data/secrets.env` 内容读入或回显；不过 `android/keystore.properties` 内容。设置页实现不得把令牌写入日志。
