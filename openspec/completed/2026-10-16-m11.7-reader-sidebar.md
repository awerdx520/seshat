## 背景

M11.3/M11.5/M11.6 已让阅读器具备批注采集、翻译/解释、离线队列，但三类信息的展示都是**临时的**：

- 批注列表用 `pop-to-buffer` 抢占阅读窗口（`emacs/seshat-reader/seshat-reader-annotation.el:382`），且 `--render-list` 被 delete/refresh 反复调用（`:384`、`:438` 段）；
- 译文/解释用 go-translate 的 posframe 悬浮展示（`emacs/seshat-reader/seshat-reader-translate.el:122` 的 `seshat-reader-translate-render` 仅允许 `pop`/`pin`），默认 30s 自动消失（用户已在 `thomas-emacs/lisp/init-tools.el:118` 调至 90s，仍会消失且是**全局**参数）。

结果：阅读时无法「边读边看」——信息不常驻、抢占阅读区、无法回看与交互。本步引入**底部弹出信息面板**（pop 样式，形如 `*Help*`）承载体与渲染层。

**最小集成步骤（若将来迁移，供另立计划参考）**：① 四仓库以 vendored 目录或 submodule 落位并 `make compile`；② `load-path` 必须**同时**加入四仓库根与各自 `lisp/` 子目录（缺 `lisp/` 会导致 `require 'etaf-ui-basic` 等失败）；③ `(require 'etaf-ui)` + `etaf-mount`/`etaf-view` 声明式构建视图；④ 复用本项目 action list 弹出；⑤ 集成点用 `condition-case` 包裹，`require` 失败回退纯文本渲染；⑥ 真机 GUI 会话补验。

## 目标

1. 阅读器提供**底部弹出的常驻信息面板**（pop 样式，形如 `*Help*`），承载批注列表与译文/解释，不再抢占阅读窗口、不再自动消失；弹出形式（当前窗口下方 / frame 底部）由 `seshat-reader-sidebar-position` 配置；
2. 面板启用/禁用、弹出位置与高度可配置；禁用时行为退回现状（`pop-to-buffer` / posframe），保证可回退；
3. 译文/解释的 posframe 改为**默认弃用**（写入面板），但保留 defcustom 可切回 posframe；
4. 面板内容本步用**纯文本 + 文本属性**渲染（零新依赖）；**不引入渲染抽象**（批注由 annotation 模块渲染、译文由 gt `gt-buffer-render` 渲染，本模块只管显示与参数），ETAF 渲染层的统一抽象待 ETAF 阶段另立（记入 tech-debt）；
5. 阶段 B（本步仅 PoC）：验证 ETAF 能在本机 checkout + `make compile` + 渲染到 buffer 并显示于底部面板，记录耗时/兼容性结论，**不改生产路径**；
6. 服务端与 Android **零改动**；不引入新依赖到 notes 仓库（ETAF 走用户配置侧加载）。

### 面板承载体（`seshat-reader-sidebar.el`）

| 符号 | 类型 | 语义 |
|---|---|---|
| `seshat-reader-sidebar-enabled` | defcustom（默认 `t`） | 是否使用面板展示；nil 时各接入点退回原行为（`pop-to-buffer`） |
| `seshat-reader-sidebar-position` | defcustom（默认 `below-selected`） | 弹出位置：`below-selected`（当前窗口下方分割，类 `*Help*`）或 `at-bottom`（frame 底部整宽） |
| `seshat-reader-sidebar-height` | defcustom（默认 `0.35`） | 面板高度（`window-height` 参数，按比例）。**仅对新建窗口生效**，改动对已显示窗口不自动重排（需重开或手动 `window-resize`） |
| `seshat-reader-sidebar-translate-buffer-name` | defcustom（默认 `"*Seshat Sidebar*"`） | 译文/解释面板的 buffer 名；同时作为 gt `gt-buffer-render` 的 `:name` 槽取值与 `gt-buffer-render-output-hook` 守卫判别的依据 |
| `seshat-reader-sidebar--display-params (&optional kind)` | 函数（内部） | 生成 `display-buffer` 的弹出 action list：`(display-buffer-below-selected)`（默认）或 `(display-buffer-at-bottom)`（`at-bottom`），附 `(window-height . HEIGHT)`（HEIGHT 取 KIND 的记忆高度，见 `--height-for-kind`）与 `(window-parameters . ((seshat-reader-sidebar . t) (seshat-reader-sidebar-kind . KIND)))`（同时携带面板判据与 kind 标记）；供 `--display` 与 gt 的 `gt-buffer-render :window-config` **共用**（面板参数单一来源） |
| `seshat-reader-sidebar--height-for-kind (kind)` | 函数（内部） | 返回 KIND 的面板高度比例：命中 `seshat-reader-sidebar--state` 的记忆值则用记忆值，否则用 `seshat-reader-sidebar-height`（KIND 为 nil 时同样回退默认值） |
| `seshat-reader-sidebar--capture-state (&optional windows)` | 函数（内部） | 对 WINDOWS（默认 `--windows` 的全部本包窗口）逐个取 `(window-parameter w 'seshat-reader-sidebar-kind)` 与 `(window-total-height w)`，换算为 `(/ (float h) (float (frame-height)))` 比例后写入 `seshat-reader-sidebar--state`（同 kind 旧值先 `assq-delete-all` 再 `cons`，零依赖 alist）；kind 为 nil、高度非正或 `frame-height` 异常（含 0）时跳过 |
| `seshat-reader-sidebar--display (buffer kind)` | 函数（内部） | 显示**必须经** `display-buffer`：先 `setq` 记录 `--last-kind`/`--last-buffer`，再 `--capture-state` 捕获现有本包窗口的实测高度（**必须在关闭窗口之前**），随后按 kind 分派——kind 相同则直接 `display-buffer` 复用（幂等、不动用户高度）、kind 不同则先关闭本包全部窗口再按 KIND 记忆高度新建、无窗口则按记忆高度新建；**不得**绕过 `display-buffer` 直接操作窗口；返回窗口 |
| `seshat-reader-sidebar-show (buffer kind)` | 函数 | 对外统一入口：`enabled` 为真时走 `--display`，否则 `pop-to-buffer`（保证回退语义） |
| `seshat-reader-sidebar-window-p (window)` | 函数 | 判据为 WINDOW 带非 nil 的 `seshat-reader-sidebar` window parameter（由 action list 的 `window-parameters` 设置） |
| `seshat-reader-sidebar--windows ()` | 函数（内部） | 过滤 `window-list` 得本包面板窗口 |
| `seshat-reader-sidebar-toggle` | 交互命令 | 开/关**本包**面板：关闭对本包面板窗口逐个 `delete-window`（`ignore-errors`）并把 buffer 记入 `--last-buffer`；打开按最近一次 kind 重新 `show`（无则 `message` 提示先打开批注列表或译文）。**不使用 `window-toggle-side-windows`**——它是 **frame 级全量**开关（实测会一并删除/恢复 eca-chat 的 right 侧窗与 which-key 的 bottom 侧窗），跨包副作用不可接受 |

> 渲染抽象不在本步引入：批注列表由 `seshat-reader-annotation--render-list` 渲染、译文由 gt 的 `gt-buffer-render` 渲染，本模块只负责**显示与参数**；ETAF 阶段若需统一渲染层再引入抽象（记入 tech-debt）。

### 显示形式：below-selected / at-bottom（可配置）

由 `seshat-reader-sidebar-position` 选择：`below-selected`（默认，类 `*Help*` 在当前窗口下方分割）或 `at-bottom`（frame 底部整宽）。两者都是**非固定**窗口，可用 `q` 或 `seshat-reader-sidebar-toggle` 关闭；底部同一时刻只显示一个 buffer ⇒ 批注与译文**后显示者接管**（这是底部 pop 语义的必然结果，非缺陷）。若日后需要两者同屏可见，需另立方案（如恢复 side-window 作为可选 style 或上下双窗口），记入 tech-debt。

**per-kind 窗口状态记忆（2026-10-16 用户裁决）**：同一时刻只有一个底部窗口，但 `annotations` 与 `translate` **各自记住自己的高度**——切换内容前先捕获当前窗口实际高度（比例）存给其 kind，再用目标 kind 记住的高度新建窗口；同一 kind 重复显示走 `display-buffer` 复用、不重建、不重置用户手动调整的高度。首次显示某 kind 时用 `seshat-reader-sidebar-height`。

### 面板渲染路径（gt 官方推荐方式）

- **采用官方机制（用户指正，2026-10-16）**：gt 官方文档（`README-zh.org`「用于渲染输出的 gt-render 组件」与「gt-buffer-render」两节）明确 `gt-buffer-render` 为**推荐使用**的渲染器，其公开槽含 `:name` 与 `:window-config`（`gt-render-buffer.el:31-38`），且 defcustom `gt-buffer-render-window-config` 的 docstring 明写「可被 render 实例的 `window-config` 槽覆盖」。官方示例：
  ```elisp
  (gt-translator :render (gt-buffer-render
                          :name "abc"
                          :window-config '((display-buffer-below-selected))
                          :then (lambda () (pop-to-buffer "abc"))))
  ```
- **本步实现**：**不新建 render 类、不 override gt 的任何内部方法**，只用公开槽组合——`seshat-reader-translate-render` 取 `sidebar` 时构造
  `(gt-buffer-render :name <面板 buffer 名> :window-config (seshat-reader-sidebar--display-params))`，
  其中 `seshat-reader-sidebar--display-params` 返回 display-buffer action list `((display-buffer-below-selected)|(display-buffer-at-bottom) (window-height . …) (window-parameters . …))`，**与批注列表的面板显示共用同一参数生成函数**。
- **好处**：① 零自定义 render 类、零 gt 内部假设（符合官方扩展指引）；② 面板参数单一来源；③ 复用官方 buffer 的交互键（`q` 退出、`g` 刷新、`t`/`T` 切换语言、`c` 清缓存、`y` 朗读）；④ `:then`/`:if` 仍可按官方方式串联或条件选择。
- **结果文本取得**：用官方 `gt-buffer-render-output-hook`（`gt-render-buffer.el:67`）更新 `seshat-reader-translate-last-result`（供 `save-as-annotation`），或 `gt-extract-data`；**不再**从 posframe 渲染 buffer 抠 `gt-result` 文本属性。
- **面板路径下的守卫（T2 实测后修订）**：`gt-buffer-render-output-hook` 在**结果 buffer 上下文内**触发（`gt-render-buffer.el:316`，此时 `current-buffer` 即结果 buffer），且本包用 `:name` 指定**专属 buffer 名**；因此守卫不用时间窗，而在 hook 内判别 **buffer 名等于本包面板 buffer 名**（并可附加 translator 判别）时才更新 `seshat-reader-translate-last-result`——零误捕获，且不受窗口时长影响。**不改动** `pop`/`pin` 路径的 `--active` 标记与 120s 时间窗守卫（保持原样）。
- **回退**：`seshat-reader-translate-render` 取 `pop`/`pin` 时仍构造 `gt-posframe-pop-render`/`gt-posframe-pin-render`（原行为不变）。

- **不改 vendored 文件**：`seshat-reader.el`/`-bookmark.el`/`-outline.el`/`-saveplace.el`/`render/` 一律不动；`annotation.el` 与 `translate.el` 为自研文件，允许最小改动
- **命名不变量**：新文件与全部公开符号前缀 `seshat-reader-sidebar-`
- **回退语义**：`seshat-reader-sidebar-enabled` 为 nil 时，批注列表回到 `pop-to-buffer`；翻译/解释在 `render` 仍为 `sidebar` 时**自动**退回 `pop` 同款 posframe（也可显式把 `render` 改为 `pop`/`pin`）——两条回退路径都要在 ERT 中断言
- **幂等显示**：`--render-list` 会被反复调用（delete/refresh），面板显示必须幂等，不得每次重建窗口布局
- **不依赖 posframe 内部结构**：面板渲染不得读取或修改 `gt-posframe-*` 变量；本包只使用 gt 的公开 render 接口（T2 结论为准）
- **全局参数慎改**：`init-tools.el:118` 的 `gt-posframe-pop-render-timeout 90` 是**全局**参数，本步不改（posframe 仍可切回）
- **ETAF 隔离**：ETAF 只允许 checkout 到 `~/WorkSpace/emacs-taf/` 并在用户配置侧加载；**禁止**把 ETAF 源码或依赖写入 notes 仓库；**禁止**修改 `.local/` 下第三方源码
- **测试不触网、不写用户文件**：ERT 一律桩化；译文面板 buffer（默认 `*Seshat Sidebar*`）用临时 buffer 名或 `let` 绑定
- **密钥保护**：报告中不得出现任何令牌/key 值；探测只用 `[ -n "$VAR" ]` 或 `${VAR:+set}`
- **面板显示必须经 `display-buffer`**：不得绕过 `display-buffer` 直接操作窗口（幂等性依赖其复用逻辑）
- **只用 gt 官方公开接口**：翻译/解释的面板渲染走 `gt-buffer-render` 的 `:name`/`:window-config` 槽与 `gt-buffer-render-output-hook`（官方推荐路径）；**禁止** override gt 内部方法或依赖其私有槽——若 T2 发现官方路径不可行，须先报告再改设计
- **`toggle` 不得用 `window-toggle-side-windows`**：它是 frame 级全量开关，会连带删除/恢复 eca-chat 与 which-key 的侧窗；本包只做本包面板窗口的 `delete-window`
- **高度**：`window-height` 只对新建窗口生效；底部窗口可用 `q` 关闭
- **范围纪律**：不做同屏多 section、不做高亮、不做 ETAF 生产迁移、不做译文历史、不做 Android/Web —— 越界即停并报告
- **tech-debt 清单（T11 统一记录）**：M11.4 侧 —— ① `rect` 无高亮承载；② EPUB location 未定导致链接只到书不到页；③ `:complete` 未实现；④ 目标文件固定末尾插入（无 headline 定位）；⑤ 含 `#`/`%` 的文档名不支持引用；⑥ `:export` 未定制；⑦ `--parse-link` 对尾部 `#` 返回空串 location（对称性小瑕疵）；⑧ 反向解析按 tag 精确匹配、同 tag 多根时只取第一个（tag 需唯一）。M11.7 侧 —— ⑨ 底部单窗口下批注与译文互斥（后显示者接管）；若需同屏可见需另立方案；⑩ ETAF 渲染层未迁移（PoC 结论待记录）；⑪ 包内窗口语义暂为两套（`outline`/`reference` 仍 `pop-to-buffer`）；⑫ `window-height`（`seshat-reader-sidebar-height`）只对新建窗口生效，改动对已显示面板不自动重排；⑬ 底部面板下译文会接管、顶掉批注列表（已确认为设计行为；若后续要求同屏则需统一 section 渲染）；⑭ 面板渲染抽象（ETAF 迁移点）未引入——当前批注由 annotation 渲染、译文由 gt 渲染，若 ETAF 阶段需统一渲染层再抽象；⑮ `seshat-reader-sidebar-toggle` 无法重开译文面板——译文由 gt 自行 `display-buffer`，不经过 `sidebar-show`，故不记录 `--last-kind=translate`；如需恢复需在 gt 渲染处加 `:then` 回调记录；⑯ ETAF 渲染层未迁移——PoC 判**可行**（2026-10-16：零警告编译、0.09s 加载、0.002s 首渲染、+6.7MB、无 native 依赖），集成需 vendored/submodule + 四仓库 load-path（含各 `lisp/`） + 降级闸门；另立计划；⑰ per-kind 窗口高度状态（`seshat-reader-sidebar--state`）仅**会话内**记忆（内存 alist），重启 Emacs 后各 kind 回到 `seshat-reader-sidebar-height`，不持久化
