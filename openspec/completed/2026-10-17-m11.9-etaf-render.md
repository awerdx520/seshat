## 目标

1. 新增 `seshat-reader-etaf.el` 渲染层（软依赖 `etaf-ui`）：批注列表渲染为**卡片列表**（标题栏 + 页码徽章 + 摘要 + `[待同步]` 标记 + 选中高亮 + 底部键位提示）；译文面板渲染为**排版布局**（标题 + 可折叠原文 + 译文正文 + 操作提示）。
2. 交互由 ETAF 承担：`:keys`（`RET`/`d`/`C-c C-r`/`q`）+ `:on-press`（选中）+ `n`/`p`（上下移动并滚动可见）。
3. ETAF 不可用（或用户关闭开关）时**自动回退**现有纯文本渲染，行为不变。
4. 依赖不入 notes 仓库：ETAF 留在 `~/WorkSpace/emacs-taf/`，由 thomas-emacs 侧 `load-path` 加载。
5. M11.8 的 **T7（面板内键位）** 由本步的 ETAF `:keys` 承担并在本步完成；**T6（全局入口 `SPC o P`）不属于本步**，仍留在 M11.8 由用户/后续批次独立完成（`:keys` 只作用于面板 buffer 内部，技术上无法承担全局入口）。

### 渲染层接口（`seshat-reader-etaf.el`）

| 符号 | 语义 |
|---|---|
| `seshat-reader-etaf-enabled` | defcustom（默认 `t`）：渲染层总开关 |
| `seshat-reader-etaf-available-p ()` | `(and seshat-reader-etaf-enabled (require 'etaf-ui nil t) t)`，结果缓存 |
| `seshat-reader-etaf-render-annotations (buffer items doc-id)` | 渲染批注面板到 BUFFER；ITEMS 为 plist 列表 `(:id :uuid :page :text :dirty :location)`：服务端项 `:id` 有值、`:uuid` 为 nil；本地待同步项 `:id` 为 nil、`:uuid` 有值（来自队列条目）；顺序**服务端项在前、本地待同步项在后**（与 `--render-list` 现有语义一致）；**幂等**（已挂载则改 ref 增量刷新） |
| `seshat-reader-etaf-render-translate (buffer &key title source body)` | 渲染译文面板；BODY 支持增量更新 |
| `seshat-reader-etaf--selected` / `--items` | 内部 `etaf-ref` 状态 |
| 动作命令 | `seshat-reader-etaf-annotation-goto` / `-delete` / `-insert-reference` / `-quit`：从 selected-id 查缓存 items 取 `location`/`id`/`uuid`/`text`，再调**底层能力**（`seshat-reader-goto-page`、`seshat-reader-annotation-delete`、`seshat-reader-annotation-queue-remove`、`seshat-reader-reference--format-block` + 写文件、`seshat-reader-sidebar-toggle`）——**不调用**依赖行文本属性的交互命令 `list-goto`/`list-delete`/`insert-annotation` |

### 交互映射

| 键 | 动作 | 实现 |
|---|---|---|
| `RET` | 跳转到选中批注所在页 | `:keys` → 读 selected-id → 查 entries 的 `location` → `seshat-reader-goto-page` |
| `d` | 删除选中批注 | `:keys` → 服务端项：`seshat-reader-annotation-delete`（含离线队列语义）；本地待同步项：`seshat-reader-annotation-queue-remove` |
| `C-c C-r` | 插入引用到笔记 | `:keys` → 用 `seshat-reader-reference--format-block` 组装摘录块后写入目标笔记（复用 reference 模块的底层函数，不调用依赖行属性的交互命令） |
| `n` / `p` | 上下移动选中项 | `:keys` 覆盖 ebox 默认滚动；改 selected-id + `etaf-scroll-into-view` |
| `q` | 关闭面板 | `:keys` → `seshat-reader-sidebar-toggle`（保留 per-kind 高度捕获） |
| 鼠标点击行 | 选中该行 | `:on-press` |

- **本地待同步项的动作路径**：`d` 走 `seshat-reader-annotation-queue-remove`（按 `:uuid`，**不发 HTTP**）；`C-c C-r` 的正文取队列条目 `:text`；`RET` 用其 `:location` 解析页码。

### gt 集成（官方机制组合）

- `seshat-reader-translate--render-object 'sidebar` 构造：
  `(gt-buffer-render :name " *Seshat gt*" :window-config '((display-buffer-no-window) (allow-no-window . t)) :then (lambda (&rest _args) ...))`
- `:then` 回调：从 gt 的隐藏 buffer 取纯文本（复用既有 `--extract-result` 逻辑）→ 调 `seshat-reader-etaf-render-translate` → `seshat-reader-sidebar-show`
- **只使用公开槽/公开机制**（`:name`/`:window-config`/`:then`），不 override gt 内部方法
- 保留 `pop`/`pin` 回退路径不变

- **坑 1（审查发现，代码级）**：`gt-buffer-render` 的 `gt-output` 在渲染完成（state=3）时会执行**不带 action 的** `(display-buffer buf)`（`gt-render-buffer.el:378-384`，`gt-buffer-render-follow-p` 默认 nil）——`:window-config` 只在 `gt-init` 阶段生效，**管不到这一处**，隐藏 buffer 仍会被弹出来。
  **对策（只用官方机制）**：在 thomas-emacs 侧加一条 `display-buffer-alist` 规则把中转 buffer 映射为不显示：
  `("\\*Seshat gt\\*" (display-buffer-no-window) (allow-no-window . t))`（配合 `:name " *Seshat gt*"`；注意名字两侧空格与正则转义需一致；缺 `allow-no-window` 时 `display-buffer-no-window` 返回 nil 会回退默认动作，**仍会弹窗**，见 F12）。
- **坑 2（审查发现，代码级）**：`:then` 为函数时以**1 个实参**调用——`(pdd-funcall then (list translator))`（`gt-core.el:1590-1603`）。故回调必须写成 `(lambda (_translator) ...)`（或 `(&rest _)`），**不能**写成无参 `(lambda () ...)`，否则 `wrong-number-of-arguments`。
- `:then` 回调内通过固定 `:name` 定位中转 buffer（`get-buffer " *Seshat gt*"`）取文本，不依赖 render 对象。

## 注意事项

- **不 vendored ETAF**：依赖只存在于 `~/WorkSpace/emacs-taf/` 与 thomas-emacs 的 load-path；notes 仓库零新增依赖文件
- **只用 ETAF 公开接口**：组件/Host 属性/`:keys`/`:on-press`/`etaf-mount`/`etaf-unmount`/`etaf-runtime-update-host-content`；不碰私有函数
- **不 override gt 内部方法**：gt 侧只用 `:name`/`:window-config`/`:then`（官方机制）
- **降级三态必须覆盖**：`enabled=nil` / require 失败 / 渲染抛错
- **evil 共存**：`:keys` 走 emulation 层最前，理论上优先；真机必须验证
- **性能**：条目 >100 用 `:overflow 'scroll`；选中切换只改 ref；不整树重渲染
- **主题**：颜色一律用 `etaf-theme-token`（不硬编码），真机在明暗主题各确认一次
- **生命周期**：buffer kill 依赖 ETAF 自动 unmount；额外自建的 timer（若流式节流）必须随 buffer 清理
- **命名不变量**：新符号前缀 `seshat-reader-etaf-`；内部 `--`
- **计划文件编辑方式**：用「读全文 → 内存替换 → 整体写回」并先备份（本仓库曾发生编辑截断）
- **范围纪律**：不做 vendored、不做逐 token 流式、不做批注编辑、不做 ETAF 版本管理 —— 越界即停并报告
- **T2 新增技术债**：⑱ ETAF 在 pty（`script -qec … emacs -Q -nw`）下 `etaf-mount` 会挂起，真机正常（用户已确认）；影响：终端-frame 用户可能不可用，需真机/图形 frame ⑲ ETAF 主题 token 不随明暗变化，本渲染层自带双色板但主题切换需重新渲染面板
- **Makefile 可选依赖探测（T3 偏差，已采纳）**：`emacs/seshat-reader/Makefile` 增 `ETAF_ROOT ?= $(HOME)/WorkSpace/emacs-taf`，存在则给 `EMACS` 加四仓库根 + 各自 `lisp/` 的 `-L`；否则把 `seshat-reader-etaf.el` 从编译/checkdoc 列表剔除（`etaf-view` 是宏，编译期必须有 etaf-ui）
- **T4/T5/T6 实测结论与设计微调（2026-10-17）**：① 列表容器 `:ref` 传**变量**（`seshat-reader-etaf--list-ref`）可用——batch 渲染后 `etaf-runtime-host-node` 能解析该 ref，`etaf-scroll-into-view` 与卡片级 ref（`seshat-etaf-item-<key>`）均正常，**保留原设计、未退回每卡片 ref**；② `etaf-button :on-press` 传**函数符号**可用（handler 表里保存的就是符号，`etaf-dispatch-event` 用 `funcall` 调用），未改 lambda；③ uuid 删除路径改为**缓存重渲染**：新增 `seshat-reader-etaf--cached-annotations` / `--rerender-cached`（服务端项取 `seshat-reader-annotation-list-entries`、本地项重读队列文件），不再走 `--refresh-list` 的 GET；④ **本轮新发现的真实缺陷（已修）**：`seshat-reader-annotation--render-list` 原本无条件 `erase-buffer`，ETAF 已挂载时随后的 `etaf-runtime-flush` 报 `Args out of range: 20, 20` → 整块回退文本渲染（影响**所有**刷新路径，不止 uuid 删除）；现改为「已挂载则不 erase，交给渲染层增量刷新」（新增 `seshat-reader-annotation--etaf-mounted-p` + 声明 `etaf-runtime-for-buffer`）；⑤ L1 收尾：`translate.el` 补 `declare-function`（`seshat-reader-etaf-available-p`/`-render-translate`）并修 checkdoc 首行大写，另在 `eval-when-compile` 用 eieio 的 `slot-name` 符号属性登记 gt 的 `taker`/`render` 槽名，消除 2 条既有「Unknown slot」告警——本包三文件现为零 warning；⑥ batch 陷阱：对已挂载 keymap 的 `lookup-key` 返回值做 `%S` 打印会挂起（打印陷阱，非功能问题），键解析须断言 `(commandp (etaf--keys-binding …))` 而非打印返回值
- **软依赖模块的 require 必须 ignore-errors**：`seshat-reader-etaf.el` 顶部是硬 `(require 'etaf-ui)`，故在无 ETAF 的环境里对它 `(require 'seshat-reader-etaf nil t)` 仍可能抛错（NOERROR 只吞「找不到文件」）——测试文件与所有调用点必须用 `ignore-errors` 包裹；`available-p` 内部已用 `condition-case` 兜底
- **T10 前补齐的两处缺口（2026-10-17，小改动、不加新功能）**：① `translate.el` 的 `sidebar` 分支在 `fboundp` 判断**之前**加 `(ignore-errors (require 'seshat-reader-etaf nil t))` —— 渲染层平时由批注列表渲染路径首次拉起，「先 `C-c C-t` 翻译、再开批注列表」时 ETAF 排版会静默失效（走 gt 原样）；现改为主动按需加载、加载失败即回退，不影响翻译本身。batch 实测：未预加载时调 `--render-object 'sidebar` → `(featurep 'seshat-reader-etaf)` 变 t、渲染对象指向隐藏中转 buffer（` *Seshat gt*`）；无 ETAF 时仍降级到展示 buffer 且不报错。② `seshat-reader-etaf-test.el` 增 `--available-p-does-not-signal`（14→15 例），断言「`require` 抛错时 `available-p` 返回 nil 且不写缓存」，且**不用** `condition-case` 包裹断言本身，否则「不冒泡」这条不变量就测没了；连带修正 `seshat-reader-sidebar-test.el` 的 `--translate-sidebar-render-object`：原用例依赖「渲染层尚未加载」这一已被本修补推翻的前提，现改为「先 `require` 渲染层、再 `cl-letf` 桩 `available-p` 为 nil」（顺序不可颠倒——桩会被 `require` 期间的 `defun` 覆盖），有/无 ETAF 两种环境均 17/17 通过
- **T10 第 1 轮反馈（2026-10-17 用户真机）与修复**：
  ① **译文面板无光标跟随** → `seshat-reader-sidebar-show`/`--display` 增可选 `SELECT` 参数，批注与译文都传 `t`（popper 重开两条路径也一致）；`--display-params` 仍受 `seshat-reader-sidebar-select-window` 总开关约束。
  ② **「来源：第 x 页」重复** → 全仓仅 `--selection-origin` 一处生成该文本，gt 无此字面量；重复源于**正文管线未过滤**（gt 提取失败会回退整个 buffer-string，带原文/头部）。修法：`--drop-origin-lines` 在正文渲染前剔除以 `来源：`/`来源:` 开头的行；**原文展开区不过滤**（忠实摘录）。
  ③ **排版不协调** → 根因：用户主题为暗色（`doom-vibrant`），而 `etaf-label`/`etaf-badge` 的文字色/底色写死（`#252A2E`/`#FFFDF8`）且**覆盖父 Host 的 `:color`**（face 属性实测）；改为**全部文字走本项目双色板 + 普通 `text`（样式放父 Host）**，仅按钮用 `etaf-button`（支持 `:color`/`:bgcolor` 覆盖）。
  ④ **修复 ② 时的二次缺陷**：`--origin-line-regexp` 与行尾锚 `\\'` 拼用导致只匹配空行、一条也删不掉 → 改为只锚行首 `"[ \t]*来源[：:]"`（实测重复由 2 次降为 1 次）。
  ⑤ **修复 ③ 时的二次缺陷**：选中标记 `▌`(U+258C) 被 ETAF 按 **2 列**测量，`(ch 1)` 会裁成空格 → 标记列宽改 `(ch 2)`、文案改 `"▌ "`（卡片整体右移 1 列）；另实测 `:border-left-*` 无效（故用前缀标记）、普通函数不能直接作 Host 子节点（须 `(expr …)` 包装）。
  ⑥ **已知限制**：配色只用内置双色板（按 `background-mode` 明/暗），不跟随具体主题变量；换主题后需重新渲染面板。
