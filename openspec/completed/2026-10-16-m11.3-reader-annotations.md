## 背景

阅读器已能取到页面文本（M11.2b：拖拽选区 → 页坐标 → 文本），但产生的判断无处可存：写入通道虽已具备（服务端 `POST /api/annotations`），却缺少**稳定的文档标识**与**稳定的位置约定**——电子书不在笔记同步域内（书库位于 `~/WorkSpace/`，而笔记根是服务端 `webdav.root`），现有 `document_id` 约定（笔记相对路径，见 `emacs/seshat-sync-cmd.el:188`）无法覆盖电子书。

本步把「能取到文本」推进为「能存住批注并跨端可读」，且两个约定必须**一次定义、M7（uid 化）时可一处替换**。

服务端现状（事实✓）：`internal/api/server.go` 的 `routes()` 已注册 `POST /api/annotations`、`GET /api/annotations?document_id=`、`PUT /api/annotations/{id}`、`DELETE /api/annotations/{id}`；`internal/storage/state.go` 的 annotations 表字段为 `(id, document_id, location, text, created_at, updated_at)`；`docs/api.md` 明确 `document_id` 由客户端约定、服务端仅按字符串精确匹配。

**关键技术前提（首轮审查实测发现，本计划据此修订）**：`emacs/seshat-rest.el` 位于**父目录**，而包内 `Makefile` 的 `EMACS` 变量只有 `-L .`、`thomas-emacs` 的运行期 load-path 也只含 `seshat-reader/` 目录——**两处都够不到 `seshat-rest`**，故本计划新增 T3 专门打通。

## 目标

1. 在阅读器内把「鼠标选区」变为**可持久化批注**（写入服务端 REST，不写回 PDF，即「侧车」）；
2. 定义并落地**文档标识约定**（`<根标签>:<相对路径>`）与**位置约定**（`page:<n>;rect:<x0>,<y0>,<x1>,<y1>`），二者集中在单一函数派生，供 M7 一处替换为 uid；
3. 提供批注**列表查看与跳页**，形成最小可用闭环（不含页面高亮可视化）；
4. 服务端**零改动**；不引入第三方依赖（复用 `url.el` / `json.el`，经既有 `seshat-rest.el`）。

### 约定（用户已确认 D1–D5）

| # | 约定 | 取值 |
|---|---|---|
| D1 | `document_id` | `<根标签>:<相对路径>`，如 `ebook:d2l-zh.pdf`；由 `seshat-reader-annotation--doc-id` 单点派生；**未命中任何已配置根**时降级为 `local:<绝对路径>` 并 echo 警告「不跨端共享」 |
| D2 | `location`（PDF） | `page:<n>;rect:<x0>,<y0>,<x1>,<y1>`；`n` 为 **1-based** 页码；rect 为**页面坐标**（PDF point 空间、原点左上、y 向下），不含缩放/旋转 |
| D3 | 批注正文 | 默认 `text` = 选中的文本；`C-u` 前缀时提示输入自定义正文 |
| D4 | 根映射配置 | 包内 `seshat-reader-annotation-roots` 默认 `nil`；实际根在 `thomas-emacs/lisp/init-reader.el` 配置（如 `'(("ebook" . "~/WorkSpace/e-book/"))'`） |
| D5 | 顺手补齐 | `seshat-rest-update-annotation`（服务端已支持 `PUT /api/annotations/{id}`）；列表 buffer 内 `RET` 跳页复用既有 `seshat-reader-goto-page` |

### 位置与页码基数（易错点，务必遵守）

- `seshat-reader-current-doc-pagenumber` 返回 **1-based**（来源：`seshat-reader.el` 中该函数读取窗口参数 `page`，而 C 侧写入时已 `+1`）；
- `seshat-reader-dyn--text-in-rect` 的 `page` 参数是 **0-based**（`seshat-reader-select-extract` 内部局部变量 `page` 已被 `1-` 处理）；
- 因此**对外写入 `location` 的页码一律 1-based**；若复用 `select` 内部的 0-based 局部变量，必须 `1+` 还原。

### 已知限制（不在本步修复）

- **页面旋转**（`rotate≠0`）时坐标为**静默错误**：旋转状态只存在于 C 侧 `EmacsWinState`，Lisp 无 API 可读（见 `seshat-reader-select.el` Known limitations）。本步**不做运行时检测**，仅在此静态说明；如需检测须另立「C 侧暴露旋转状态」的前置任务。
- 无页面高亮；批注仅通过列表 buffer 呈现（页码 + 摘要 + `RET` 跳页）。

### 数据流

`down-mouse-1` 拖拽 → `seshat-reader-select-drag` → `seshat-reader-select-extract` 得到文本与页坐标 → 写入 `seshat-reader-select-last`（text / page(1-based) / rect / file）并 echo 提示 → 用户 `C-c C-a` → `seshat-reader-annotation-create` 组装 `document_id` 与 `location` → `seshat-rest-create-annotation` → 服务端；`C-c C-l` → `seshat-rest-list-annotations` → 渲染 `*Seshat Annotations*`（页码 + 正文摘要，`RET` 跳页，`d` 删除）。

### 明确不在本步（范围外）

页面**高亮可视化**、批注**备注字段**（服务端 schema 扩展）、**EPUB** location 约定（M10.3 未决）、**离线队列／重试**、**选区去重**、**双向引用**（M11.4）、**Android/Web 端**适配。

- **安全点放持久位置**：M11.2c 中 `/tmp/seshat-backup/` 被系统清理导致基线丢失，本计划要求备份到 `~/.local/share/seshat-backup/`
- **密钥保护**：只探测 `SESHAT_AUTH_TOKEN` 是否存在（`[ -n "$SESHAT_AUTH_TOKEN" ]` 或 `${SESHAT_AUTH_TOKEN+set}`），**禁止**回显其值，也禁止把带令牌的完整命令输出粘进报告
- **命名不变量**：新文件与全部公开符号必须带 `seshat-reader-annotation-` 前缀（延续 M11.2c 确立的自研化约定）
- **不改 vendored 逻辑**：`seshat-reader-select.el` 只新增「最近选区」变量与提示，不改既有选区→文本行为
- **两处 load-path 必改**：编译期 `Makefile` 的 `-L ..`（T3）与运行期 `init-reader.el` 的父目录 load-path（T9）——缺一即失败
- **页码基数**：对外 `location` 一律 1-based；`select` 内部局部变量是 0-based，复用须 `1+`
- **不做旋转检测**：Lisp 无法读取旋转状态，本步仅静态说明该限制，不写运行时检查
- **测试不触网**：ERT 一律用 `cl-letf` 桩替 `seshat-rest--request`；L3 才用真实服务端
- **不写回 PDF**：批注仅存服务端（侧车），不得修改用户电子书文件
- **范围纪律**：不做高亮可视化、不做备注字段、不做 EPUB 约定、不做离线队列、不做选区去重——越界即停并报告
- **REST 失败必须显式报错**（`message` 或 `user-error`），不得静默吞掉
- **L3 待补**：M11.3 的端到端闭环（Emacs 建批注 → 服务端查到 → Emacs 列表拉到 → 删除 → 确认消失）需在服务端可用时补做；启动方式见 `docs/configuration.md` 与 `deploy/`（需先设置 `SESHAT_AUTH_TOKEN`/`SESHAT_DB_KEY` 等密钥，密钥值不得写入任何仓库文件）
