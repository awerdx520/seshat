### PDF 渲染管线（连续滚动）

| 组件 | 设计 |
|---|---|
| 容器 | **单一 `RecyclerView`**（替换 `ViewPager2`）：横向 = `LinearLayoutManager(HORIZONTAL)` + `PagerSnapHelper`；竖向 = `LinearLayoutManager(VERTICAL)`，页间零间隙 |
| 适配器 | `PdfPageAdapter` 重构：`onCreateViewHolder` **按 mode 分支**建 LayoutParams——横向 `MATCH_PARENT × MATCH_PARENT`（`FIT_CENTER`）、竖向 `MATCH_PARENT × WRAP_CONTENT`；竖向在 `onBindViewHolder` 渲染后把 `(renderWidth × pageH / pageW)` 算出的像素高**写回 `imageView.layoutParams.height`** 并 `requestLayout()` |
| 渲染 | `Executors.newSingleThreadExecutor()`（`PdfRenderer` 非线程安全，必须串行）；渲染中先显示占位白底；`onDestroy` 调用 `shutdownNow()` 并在回调前检查 `isFinishing` |
| 缓存 | `LruCache<Int, Bitmap>`，上限 `Runtime.maxMemory()/8` |
| 预渲染 | 目标页 ±2 页 |
| 进度 | 首个 `findFirstVisibleItemPosition()` 经 `ScrollProgressMath` 换算 → 页码；恢复：横向 `scrollToPosition`、竖向用 `scrollToPositionWithOffset(pos, -offset)`；`previousItemHeight` 由调用方从上一项 `layoutParams.height` 或 adapter 的高度缓存注入 |

### EPUB 渲染管线（连续滚动）

| 组件 | 设计 |
|---|---|
| 容器 | 两套并存、按 `reader_page_mode` 显示其一：`ViewPager2` + `ChapterFragment`（横向，既有）/ **`RecyclerView` + 新 `ChapterScrollAdapter`**（竖向） |
| 竖向 item | `WebView`：`onPageFinished` 后用 `evaluateJavascript("document.documentElement.scrollHeight")` 取 CSS 高度 × `density` 设为 item 高度；`isNestedScrollingEnabled = false`（禁 WebView 自身滚动）；测量前用屏高占位。**完整时序**：占位高度 → 加载 → 测量 → `notifyItemChanged(pos)` → 高度变化会使已滚动位置漂移，若该章为当前可见章必须用 `scrollToPositionWithOffset(pos, -当前章内偏移)` **重锚**；后续章测量完成若位于当前阅读点之前，同样需要重锚 |
| 复用策略 | **禁复用（两级缓存都要关）**：`recyclerView.setItemViewCacheSize(0)`（关一级 `mCachedViews`）+ `recycledViewPool.setMaxRecycledViews(type, 0)`（关二级池），并在 `onViewRecycled` 里 `destroy()` WebView。只关二级池不够——一级缓存默认 2 个，短距离回滚仍会复用同一 WebView 且不触发 `onCreateViewHolder` |
| 进度 | **语义不变**：`ReadingProgress(chapterIndex, scrollY)`。竖向经 `ScrollProgressMath` 由「首个可见 item 的 position + `-itemView.top`」换算（`previousItemHeight` 取上一项 view 高度或 adapter 的高度缓存），恢复用 `scrollToPositionWithOffset(pos, -scrollY)` |
| 批注 | 横向取当前 `ChapterFragment` 选区（现有）；竖向取**当前可见章**的 WebView 选区（adapter 暴露 `currentWebView()`） |
| 字号 | 两模式均设 `web.settings.textZoom = appPrefs.textZoom()` |

## 注意事项

- **TDD 强制**：T1 的两个测试文件必须先写并见红，再写实现。
- **既有测试是护栏**：179 例中任一失败视为回归，修代码不改期望。
- **不破坏 M9.1 的安全不变量**：令牌仍只经 `putSecret` 写入；设置页的 `FLAG_SECURE`、Autofill/`saveEnabled`、`onPause` 清空、校验错误码化全部保留。
- **`AppPreferences` 不得依赖 `SecurePrefs`**（非机密层与加密层解耦）；prefs 文件名固定为 `seshat_app_prefs`。
- **`PdfRenderer` 单线程**：所有 `openPage`/`render` 必须在同一后台线程串行执行；`onDestroy` 后不得再触碰 `renderer`。
- **`RecyclerView` + `WebView` 禁复用（两级缓存都要关）**：`setItemViewCacheSize(0)` + `recycledViewPool.setMaxRecycledViews(type, 0)`，并在 `onViewRecycled` 里 `destroy()`；只关二级池时一级缓存（默认 2 个）仍会复用 WebView，导致空白页或滚动锚点漂移。
- **WebView 高度单位**：JS 返回的是 CSS px，需乘以 `resources.displayMetrics.density` 才是 View 像素。
- **字符串前缀**：新增设置文案用 `settings_*`；阅读偏好用 `reader_pref_*`；不得与既有 `reader_*` / `main_*` / `gtd_*` / `import_*` / `tab_*` 冲突。
- **零新增依赖**：不引入 coroutines / WorkManager / Compose / Navigation；网络仍用 OkHttp，线程仍用 `Thread` + `Executor`。
- **无设备**：滚动流畅度与高度测量时序无法自动验证，必须在交付说明中如实标注，并在 tech-debt 记录。
- **备份**：`seshat_app_prefs.xml` 不含机密，**不加入**备份排除规则（与 `seshat_sync*.xml` 区别对待）。
- **不得读取** `android/keystore.properties`、`release.keystore`、`data/secrets.env`。
