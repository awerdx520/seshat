### B1 设计（P0 修复）

**B1.1 服务端可选（配置解耦）**

| 场景 | 行为 |
|---|---|
| 地址留空 + 令牌留空 | 允许保存；只写本地偏好；**不触碰**已存服务端配置 |
| 地址留空 + 令牌有值 | 允许保存：**新增 `SettingsStore.saveTokenOnly(token)`**（走 `writeSecret(KEY_AUTH_TOKEN, token)`，仍校验令牌非法字符；加密不可用返回 false 并触发告警），本地偏好照写；地址保持原值不变 |
| 地址有效 | 原流程（URL 校验 → 令牌校验 → `store.save`） |
| 地址非法 | 仍拦截并内联报错（`ftp://`、userinfo、query 等） |

实现：
- `settings/SettingsValidator.kt`：新增 `UrlValidation.Empty`（**合法**状态，与 `Error` 区分；`validateServerUrl("")` 与纯空白返回 `Empty`）。
- `settings/SettingsActivity.kt`：`save()` 重构为「校验 URL → （仅当 Ok 时）写服务端配置 → 写本地偏好 → finish」；`Empty` 分支跳过服务端写入但**继续写本地偏好**。
- 语义：清空地址**不等于**删除已存服务端配置（避免误删）；删除走「重置本地配置」。
- 文案：`settings_server_optional_hint`（"留空则仅本地使用，不同步服务器"）。

**B1.2 EPUB 章节标题滞后**

- 根因：`reportVisibleChapter()` 用 `findFirstVisibleItemPosition()`，短章多章同屏时取到"顶部那章"，而用户在看"占据视口中心的那章"。
- 修法：抽纯函数 `reader/ScrollProgressMath.kt` 新增
  ```kotlin
  data class ItemBounds(val position: Int, val top: Int, val bottom: Int)
  fun visibleCenterPosition(items: List<ItemBounds>, viewportCenter: Int): Int?
  ```
  返回覆盖 `viewportCenter` 的 item 的 position；无覆盖时返回最接近者；空列表返回 null。
- `EpubReaderActivity.reportVisibleChapter()`：用 `findFirstVisibleItemPosition()..findLastVisibleItemPosition()` 采集 `ItemBounds`，调上述函数得到**中心章**。
- **章内偏移必须基于中心项自身**：`scrollY = (-centerView.top).coerceAtLeast(0)`，即「中心项顶部已滚出视口的像素」；**不得**复用 `progressFromViewport(first, …)` 的 offset（那是相对 first 可见项的滚出量，中心项不是 first 时会把偏移算错）。
- `onChapterMeasured()` 的重锚也用同一 `scrollY`（`scrollToPositionWithOffset(中心章, -scrollY)`），保证测量完成后阅读位置不跳。
- 测试：`ScrollProgressMathTest` 新增 ≥5 例（中心落在第一项 / 落在第二项 / 落在两项交界取后者 / 空列表 null / 中心越界取最近）。

### B2 设计（阅读器对齐静读天下）

| # | 能力 | PDF | EPUB |
|---|---|---|---|
| 1 | tap 中央显隐工具栏 | 已有 `toggleChrome()`，仅需确认覆盖区与阈值 | 新增：`GestureDetector` + `onInterceptTouchEvent` 恒返回 false；切换标题栏 + 底部按钮栏 + 浮层 |
| 2 | 可拖 SeekBar + 页码/章节可点跳转 | 底部 `SeekBar`（0..pageCount-1）+ 点页码弹「跳转到第 n 页」输入框 | 底部 `SeekBar`（0..chapterCount-1）+ 点标题弹「跳转到第 n 章」输入框 |
| 3 | 章节目录 | 不做（PDF 无 TOC 数据源） | 底部「目录」按钮 → 列表对话框：序号 + 标题 + 当前章高亮 → 点击跳章并关闭 |

约束：SeekBar 只做**粗粒度**（页码 / 章节），不做章内偏移细粒度拖动；拖动结束才跳转（避免拖动过程反复 seek）。

**EPUB 布局改造幅度（重要）**：`activity_epub_reader.xml` 当前是 `LinearLayout`（标题栏 / 容器 / 按钮栏为普通子 view，**没有浮层**）。B2 需把它改为 `FrameLayout` + 浮层容器（标题栏与底部按钮栏改为 overlay，`layout_gravity="top"/"bottom"` + 半透明背景），才能实现「tap 中央显隐工具栏」。PDF 侧已是 `FrameLayout` + `pdfChrome`，只需在浮层内加 `SeekBar`。
